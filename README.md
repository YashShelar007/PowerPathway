# 🏋️ PowerPathway – Personalized Fitness Tracking Web App

A fitness-focused web app built with React that helps users explore 1000+ exercises, filter by muscle groups, and build personalized training routines.

### 🔗 Live Link: https://powerpathway.netlify.app/ 
### 📂 GitHub Repo: https://github.com/YashShelar007/PowerPathway

---

## 📍 Problem It Solves

Fitness planning can be overwhelming. PowerPathway makes it simple by letting users search, explore, and structure their workouts based on goals, muscle groups, or equipment using a clean UI and powerful API integration.

---

## 🛠 Tech Stack

- **Frontend**: React, Material UI, JavaScript
- **API**: RapidAPI (ExerciseDB)
- **State**: useState, useEffect hooks
- **Performance**: LocalStorage caching, Pagination

---

## ✨ Key Features

- 🔍 Search 1000+ exercises by muscle group, body part, or equipment
- 🧠 Smart filters & paginated browsing
- 💾 Local caching to reduce API usage and improve performance
- 📱 Fully responsive layout with Material UI

## 🚀 Getting Started

```bash
# 1. Clone the repo
git clone https://github.com/YashShelar007/PowerPathway.git
cd PowerPathway/power-pathway

# 2. Install dependencies
npm install

# 3. Add your RapidAPI key to `.env`

# 4. Start the development server
npm start
```
